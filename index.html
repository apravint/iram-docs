Sovereign Agentic OS Architecture

IRAM OS is an independent, turnkey 64-bit Linux distribution engineered from the ground up for modern developers, power users, and autonomous AI agent orchestration.

Compositor Engine
Hyprland 0.56 with sharp 0px geometry, acrylic blur, and sub-100ms zero-restart live theming across 43 palettes.
FastMCP Integration
Native Model Context Protocol daemon (:8991) exposing 28+ hardware, audio, and window management tools to AI agents.
Studio Audio DSP
PipeWire + WirePlumber priority routing with 1-click analog/HDMI output toggling and automated recovery.
Kernel ECMP Multi-WAN
Aggregates internal PCIe and external USB Wi-Fi adapters with L4 flow hashing and ARP flux mitigation.

context-condenser (98% BM25 Engine)

Eliminate LLM context exhaustion. context-condenser uses local SQLite FTS5 BM25 token frequency ranking to shrink logs, git diffs, and tool outputs prior to prompting.

pip install context-condenser
cat debug.log | context-condenser -q "ConnectionResetError" --ratio 0.05

agent-hindsight (Temporal Memory)

Persistent long-term memory engine for AI coding agents with half-life recency decay and semantic reflection.

pip install agent-hindsight
agent-hindsight retain "Default sink is combined_displays at metric 100" -c audio -i 5
agent-hindsight recall "audio sink"

adversarial-pre-push Gate

6-phase security auditing git pre-push gate with separated Hunter and Verifier stages to catch secrets, eval leaks, and shell injection seams.

pip install adversarial-pre-push
adversarial-pre-push install-hook /path/to/repo
adversarial-pre-push audit .

linux-dual-wifi (ECMP Multi-WAN)

Aggregates concurrent internal PCIe and external USB Wi-Fi adapters using Linux kernel Equal-Cost Multi-Path policy routing tables and layer 4 flow hashing.

git clone https://github.com/apravint/linux-dual-wifi.git
cd linux-dual-wifi && ./install.sh
dual-wifi balance
