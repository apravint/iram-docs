## ⚡ Core Subsystems & Chapters Covered

1. **Operating System Architecture:**
   - Turnkey 64-bit sovereign distribution based on Ubuntu 26.10, Linux Kernel 7.3, Hyprland 0.56, and PipeWire.
   - Interactive CLI terminal simulator with real formatted output from the unified `iram` dispatcher.

2. **FastMCP Linux Desktop Control Server:**
   - Model Context Protocol server published on PyPI (`fastmcp-linux-desktop` v0.1.0) with Glama Grade-A certified quality.
   - 28+ native JSON-RPC 2.0 tools for hardware, window management, audio DSP, and memory recall.
   - Built-in interactive JSON-RPC tool simulation sandbox.

3. **Storytold Craft Suite (The Sovereign Open-Source Creative Suite):**
   - 11 native, GPU-accelerated Rust applications replacing proprietary Adobe & Microsoft software:
     - **PhotoCraft** (Photoshop alternative - PSD layers, retouching)
     - **VectorCraft** (Illustrator alternative - Bezier vectors, SVG/AI typography)
     - **FilmCraft** (Premiere Pro alternative - 4K magnetic video timeline)
     - **SoundCraft** (Pro Tools alternative - PipeWire DAW, VST3, DSP tuning)
     - **FigCraft** (Figma alternative - UI prototyping, auto-layout, design tokens)
     - **CADCraft** (AutoCAD alternative - 2D drafting, 3D parametric STEP/STL)
     - **LightCraft**, **WordCraft**, **GridCraft**, **DeckCraft**, **PdfCraft**.
   - Interactive app comparison explorer with launch commands and native file formats.

4. **Universal Film & Video Studio Engine (`iram-video`, OpenMontage & PersonaLive):**
   - Real 1080p/4K YouTube Documentary generator (`iram video "<topic>" --real`).
   - PersonaLive Real-Time Streamable Portrait Diffusion (CVPR 2026, 12GB VRAM infinite-length avatars).
   - OpenMontage 12-pipeline agentic directing matrix with category filtering.
   - Remotion React motion graphics headlessly rendered with Chrome Headless Shell.
   - Backlot living storyboard visual inspector (`http://localhost:8080`).
   - Automated multi-point media QC inspection (`iram video --montage-audit`).

5. **ALPORA Theming & 24h Circadian Timeline:**
   - 49 curated desktop palettes with sub-100ms zero-restart live reload across all apps.
   - Dynamic 24-hour sun/sky circadian timeline (`iram theme timeline`).
   - Interactive web-based theme switcher dynamically re-styling the portal across 8 curated palettes.
   - Faceted polygon mountain system card (`iram fetch alpora`).

6. **VoiceStudio & Voxtype System Dictation:**
   - Sovereign on-device neural voice cloning, design, and dubbing (`iram-voice`).
   - System-wide whisper speech-to-text dictation (`voxtype`).
   - Hardware-calibrated PipeWire studio DSP audio tuning (`iram-audio-tuning`).

7. **Autonomous AI Agent Daemon & Sidecar:**
   - Native WebKitGTK floating Wayland AI Sidecar window (`iram-sidecar`).
   - Multi-account token failover daemon (`iram-agent-daemon`, `iram-agent-account`).
   - OpenRig swarm topology runner for continuous engineering teams (`iram-openrig`).
   - Hard capability isolation via ToolGate and Agent Jail (`agent-jail`, `iram-toolgate`).

8. **Episodic Memory & Context Compression:**
   - `context-condenser`: 98% SQLite FTS5 BM25 token compression to eliminate context exhaustion.
   - `agent-hindsight`: Long-term episodic memory engine with half-life recency decay.

9. **Kernel Networking & Adversarial Security:**
   - `linux-dual-wifi`: Aggregates internal PCIe and external USB Wi-Fi adapters via kernel ECMP policy routing.
   - `adversarial-pre-push`: 6-phase Hunter/Verifier pre-push security gate.

10. **Spatial 3D & IRAM Quant:**
    - Three.js 3D interactive desktop command universe (`iram-3d`).
    - `archify-py`: Zero-dependency repository architecture mapper.
    - IRAM Quant cross-market algorithmic stock scanner (US & NSE equities).
